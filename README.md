# Tiny PyTorch ANN (XOR)

A minimal, beginner-friendly PyTorch example that trains a small feed-forward neural network to learn the **XOR** function.

## Project structure

- `model.py` — neural network definitions
- `train.py` — trains on XOR and prints predictions

## Requirements

- Python 3.9+ (recommended)
- PyTorch

Install PyTorch (choose the right command for your system):  
https://pytorch.org/get-started/locally/
